## Intended use

Rank account-days for human review within a bank's daily review capacity, using the frozen Run A xgboost ensemble with the committed decision cut 0.9631869778454679 (comparison.json decision_cut).

Not intended for:

- Any automatic block, restriction or cash-out without a human reviewer
- Production evidence while leakage check 6b is recorded as failed
- Accounts or behaviours outside the ashFALL simulator's generation rules
- Scoring without the frozen Run A feature order

## Known limitations

- Simulator new-account cleanness: the simulator opens accounts itself and records the opening minute (world/bank_connectors.py:344-369), so a new account here has no prior history; a mule's fresh account opened with a borrowed identity is not modelled, so new-account detection is cleaner than reality.
- Capacity rounds to one per bank-day: recall at capacity uses max(1, ceil(active_accounts * capacity_pct / 100)) per bank-day (evaluation/level17_scoring.py:527), so on a bank-day with few active accounts a single review decision is the whole capacity.
- Leakage check 6b is recorded as failed in leakage.json: the account model's validation ranking exceeds the A-057 average-precision-over-base-rate limit, so these results are not production evidence.
