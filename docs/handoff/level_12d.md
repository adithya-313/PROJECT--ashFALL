## Decisions and Why
- Reactions, rotation, splitting and the market are each behind a switch, off by default, so 12a-12c output and run ids are unchanged when they are off (ground rule 13).
- The gang mind (world/gang_reactions.py) never reads truth, ledger or encumbrance state; it only receives observations. An AST test enforces this.
- Every draw function always takes its draw, so the number of draws never depends on the config.
- Resale only reuses rented mules that the seller has finished with (burned before the buyer starts), so ownership spans never overlap and the truth overlap check stays strict.
- Splitting uses equal pieces so no tiny piece appears; in training the slow_drip line is enforced.
- Families are optional so older gang configs keep their run ids.

## Known Gaps
- Liens reaching gangs come only from injected outside events; real liens arrive from Level 13 holds and Level 21 actions through the same feed.
- No family-to-block table exists; families are checked by name only (amendment A-019).
- Money the seller left in a resold account can be forwarded by the buyer, capped by the illicit guard.
- Only rented mules are resold; borrowed-KYC and business accounts are not.
- Fraud payments are still stamped with the owner's phone, not the gang device (from 12c).
- The account market and reactions have no world_ranges-based default run yet; the showcase uses fixtures.
- training_devices_retired_on_schedule (the device-rotation dividing line) is read but not enforced in code (12-8, later_work 12f).
- operator_share in config/tactic_costs.yaml is read by no code (only a shape test).
- config/showcase_level_11.yaml: tiny_world (except n_people), chart_geometry and most expected_invariants are read by no code; kept because Level 11 is frozen.
- world/gang_config.py has 4 lines over 120 characters from 12b (ruff E501), left untouched.
- tests/unit/world/test_new_code_comment_standard.py has one old mypy error (get_docstring argument type).
- Every config file now carries plain-English explanations (batches 1-5); comments only, data proven identical.
